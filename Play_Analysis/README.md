# Play_Analysis

Rule-based classifiers operating on bird's-eye (yard-space) player positions: Formation Classification, Play-Type Classification, and Yard-Line/Hash Analysis. Answers RQ3 — whether the pipeline's detections and field registration carry enough information to recover a coaching-relevant description of the play.

Each classifier is evaluated in two phases: **GT-input** (ground-truth boxes/keypoints, isolates whether the classification logic itself is correct) and **self-detected** (the deployed pipeline's own detections/tracking/homography, measures real end-to-end capability). `classify_formation.py` and `yard_hash_analysis.py` additionally support two mixed configurations (GT box + detected kpt, detected box + GT kpt) to decompose the self-detected accuracy drop into its player-detection vs. field-registration source. Play-Type Classification skips the mixed configurations, since box source and homography source aren't independent once SAM-3 tracking is involved (Section~\ref{sec:eval_play_classification}).

---

## Scripts

| Script | Output | Description |
|--------|--------|-------------|
| `classify_formation.py` | `formation_eval*.json` (4 configs) | Maps presnap skill-player alignment to one of five formations via WR counts + tackle-box geometry. |
| `yard_hash_analysis.py` | `yard_hash_eval*.json` (4 configs) | Recovers signed yard line and hash (L/M/R) from the Oline/defense bird's-eye positions. |
| `play_type_classification.py` | `play_type_eval*.json` (2 configs) | Classifies Run/Pass from QB-dropback and Oline-drive slope signals fit across the tracked trajectory. |

## evaluation/

| Script | Description |
|--------|-------------|
| `cv_formation.py`, `cv_yardhash.py`, `cv_playtype.py` | Quarter-based 4-fold cross-validation: refit each classifier's thresholds on 3 quarters, evaluate on the held-out 4th, pool all folds' predictions for the thesis's headline numbers. |
| `box_tightness_error.py` | Isolates how much detected-box "looseness" (the mAP50 vs. mAP50-95 gap) costs Formation/Yard-Hash specifically, by matching detected to GT boxes and projecting both foot points through the GT homography. |
| `list_misclassified_playtype.py` | Lists every misclassified Play-Type clip with its raw QB/Oline slopes, for manual film review. |
| `plot_misclassified_formations.py`, `plot_misclassified_hash.py` | Renders a presnap-frame + bird's-eye diagnostic figure per misclassified clip (GT and self-detected separately), output in `evaluation_output/misclassified*`. |
| `plot_playtype_trajectories.py` | Renders the Methods-section illustration: QB/Oline downfield displacement for one clean Run and one clean Pass example. |
| `main_evaluation.ipynb` | Generates the thesis's Results-chapter figures (accuracy bars, confusion matrices) for all three classifiers from the `*_eval*.json` files, into `evaluation_output/`. |

## extrinsic_evaluation/

The four Hudl-style `.xlsx` tagging sheets (generated by `Helpers/generate_extrinsic_eval_sheets.py`) used for the manual-vs.-pipeline-assisted timing comparison with two coaches (Additional Experiments, Extrinsic Evaluation).
